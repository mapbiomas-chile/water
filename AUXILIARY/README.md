# Auxiliary data — Collection 01

MapBiomas Chile — Chile Water.

GEE assets under:

```text
projects/mapbiomas-chile/assets/WATER/AUXILIARY_DATA/
```

This folder holds **build scripts** (recipes). Do not commit GeoTIFFs/shapefiles.

## Build order (once / when refreshing aux)

| Order | Script | Output asset |
|------:|--------|--------------|
| 1 | `export_biggrids_chile.js` | `VECTOR/biggrids-chile` |
| 2 | `export_shademask2_fabdem.js` | `RASTER/shademask2_FABDEM` |
| 3 | `export_slppost2_fabdem.js` | `RASTER/slppost2_30_FABDEM` |
| 4 | `../HYDROCLIMATE/` (PC notebook → upload CSVs → `complete_hydroclim_gee.js`) | `TABLE/*_merged*` (+ needs `MZ_CHILE`, `CR2MET_pp`) |

All build scripts default to `CONFIG.runExport = false` (preview). Set `true` to queue Tasks.

Hydroclimate tables stay in `HYDROCLIMATE/` (not duplicated here).

## Raster

| Asset | Path | Used by | Role |
|-------|------|---------|------|
| `shademask2_FABDEM` | `…/RASTER/shademask2_FABDEM` | Classification, step02, revision | Hard topographic shade (FABDEM + Landsat mean sun) |
| `slppost2_30_FABDEM` | `…/RASTER/slppost2_30_FABDEM` | Classification | Relative elevation / “slppost” for decision tree |
| `HAND_GLO30_CHL` | `…/RASTER/HAND_GLO30_CHL` | step02, revision | HAND (hard filter + plain rescue) — **external / prebuilt** |
| `CR2MET_pp` | `…/RASTER/CR2MET_pp` | `complete_hydroclim_gee.js` | Monthly precip stack — **prebuilt upload** |

**External DEM:** `projects/sat-io/open-datasets/FABDEM`
